# Baixar o Trajeto Inclusivo

## Windows x86_64

**[Clique aqui para baixar o ZIP Windows](https://github.com/MiguelSMaciel/Trajeto-Inclusivo/releases/download/v0.2.0/TrajetoInclusivo-Windows-x86_64.zip)** — aproximadamente 54 MB.

Extraia toda a pasta do ZIP e execute `TrajetoInclusivo.exe`. Mantenha as DLLs e as pastas junto do executável. O pacote contém as três cenas, incluindo FAESA, os dados e a documentação; não é necessário instalar o Unity Editor.

[Checksum SHA-256 do Windows](https://github.com/MiguelSMaciel/Trajeto-Inclusivo/releases/download/v0.2.0/SHA256SUMS-Windows.txt).

## Linux x86_64

**[Clique aqui para baixar o pacote Linux](https://github.com/MiguelSMaciel/Trajeto-Inclusivo/releases/download/v0.2.0/TrajetoInclusivo-Linux-x86_64.tar.gz)** — aproximadamente 49 MB.

Extraia o pacote e execute `./TrajetoInclusivo.sh` dentro da pasta extraída. Consulte o [guia Linux](../Docs/LINUX.md).

[Checksum SHA-256 do Linux](https://github.com/MiguelSMaciel/Trajeto-Inclusivo/releases/download/v0.2.0/SHA256SUMS.txt).
