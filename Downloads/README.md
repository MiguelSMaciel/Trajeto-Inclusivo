# Baixar o Trajeto Inclusivo

## Manual de uso e apresentação

Manual ilustrado de 25 páginas para Windows e Linux, com explicação das telas, campos do editor, exercícios e roteiro de apresentação de 12 minutos.

Na versão 0.3.0, consulte também o [guia de inspeção de nós](../Docs/INSPECAO_DE_NOS.md), que explica o clique nas bolinhas azuis e o botão para localizar alterações do cenário.

- [Baixar o manual em PDF](https://github.com/MiguelSMaciel/Trajeto-Inclusivo/releases/download/v0.2.0/Manual_Trajeto_Inclusivo_0.2.0.pdf).
- [Baixar o manual em Word editável](https://github.com/MiguelSMaciel/Trajeto-Inclusivo/releases/download/v0.2.0/Manual_Trajeto_Inclusivo_0.2.0.docx).
- [Ler o manual no GitHub](../Docs/MANUAL_DE_USO.md).

Para preparar a demonstração, consulte as páginas 20 a 22 do PDF ou Word. O manual é um download separado dos pacotes do aplicativo.

## Windows x86_64

**[Clique aqui para baixar o ZIP Windows](https://github.com/MiguelSMaciel/Trajeto-Inclusivo/releases/download/v0.3.1/TrajetoInclusivo-Windows-x86_64.zip)** — aproximadamente 55 MB.

Extraia toda a pasta do ZIP e execute `TrajetoInclusivo.exe`. Mantenha as DLLs e as pastas junto do executável. O pacote contém as três cenas, incluindo FAESA, os dados e a documentação; não é necessário instalar o Unity Editor.

[Checksum SHA-256 do Windows](https://github.com/MiguelSMaciel/Trajeto-Inclusivo/releases/download/v0.3.1/SHA256SUMS-Windows.txt).

## Linux x86_64

**[Clique aqui para baixar o pacote Linux](https://github.com/MiguelSMaciel/Trajeto-Inclusivo/releases/download/v0.3.1/TrajetoInclusivo-Linux-x86_64.tar.gz)** — aproximadamente 49 MB.

Extraia o pacote e execute `./TrajetoInclusivo.sh` dentro da pasta extraída. Consulte o [guia Linux](../Docs/LINUX.md).

[Checksum SHA-256 do Linux](https://github.com/MiguelSMaciel/Trajeto-Inclusivo/releases/download/v0.3.1/SHA256SUMS.txt).
